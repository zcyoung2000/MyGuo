# Browsing UI and motion review

The shared material configuration remains in `internal/uiapp/surfaces.go`.
Ordinary pages now sample the painted UI using dark tinted clear glass,
instead of sampling the brighter system material underneath the window.
Player chrome retains native glass so it can sample AVKit. Artwork overlays
use a stronger black tint to remain dark over bright posters.

Motion tokens now live in `internal/uiapp/ui_motion.go`. Page replacement
uses a 160 ms fade with a small entrance offset; replacement result sets
crossfade over 180 ms. Disclosures use MyGo's collapsible primitive, including
keyboard/assistive-technology behavior. Settings card height changes ease
over 200 ms. Native playback surface lifetime and feed motion are unchanged.

Issues fixed:

- Hover previously retargeted the same color animation to idle and then hover
  in every build. It now sets one target and settles after entering/leaving.
- Very long filter groups overwhelmed the initial viewport. They show eight
  initial choices plus any later selected choice, with the remaining options
  in a disclosure. The whole filter panel can also be opened/closed manually.
- Discover virtualization used a fixed 420 DIP filter offset, which was wrong
  for actual wrapped and expanding filters. It now uses measured panel height.
- Catalog, search, rankings and releases keep available results while updates
  are pending. Full refreshes replace a result set with a fade; pagination
  preserves existing rows. Refresh failures retain content with inline retry.
- Library result identities change only when visible membership/order changes,
  avoiding repeated fades on render. Page switching and result replacement
  preserve virtualized collection paths and stable item keys.
- Artwork fades previously rebuilt the view using AnimateTo. Stable image
  nodes now use paint-only poses/content transitions. Loading placeholders
  stop animating when the request finishes or fails. Queued requests which
  have left both viewport frames are skipped before occupying a network slot;
  visible images remain pinned in the existing bounded cache.

Validation:

- Full Go suite and vet passed; UI race checks passed.
- Behavioral regressions cover dark controls, progressive filter expansion,
  selected-option visibility, manual collapse, Reduce Motion, retained results
  after refresh/failure, settled hover, and paint-only artwork arrival.
- `TestExportBrowsingPolish` exports page previews with local poster fixtures
  and 16 timed disclosure frames. Those frames were reviewed for gradual
  layout movement. They make no API calls or account changes.
- An isolated production process loaded real upstream metadata and displayed
  an AVKit frame. MyGo screenshots checked the dark browsing surfaces. Native
  window capture returned cgWindowNotFound, so timed animation and completed
  artwork checks used MyGo's renderer/test clock instead of OS video capture.
- Signed CGO-disabled application rebuilt at
  `dist/darwin-arm64/myguo.app`; the installed app was not overwritten.

Preview reproduction:

```sh
MYGUO_POLISH_SHOTS=/tmp/myguo-polish-previews \
MYGUO_POLISH_COVERS=/path/to/local/posters \
go test ./internal/uiapp -run TestExportBrowsingPolish -count=1
```
