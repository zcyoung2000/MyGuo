# 播放器控件与防误触

以下规则取代原先“第一次点击清屏、第二次点击暂停”的交互。

推荐流的播放控件、剧名和频道常驻。点击画面或黑色留边不改变播放状态，
暂停或继续使用播放按钮、空格。滚动仍切换短剧。打开选集、评论等面板时，
点击面板外仅关闭面板。

剧集播放闲置约 4 秒后自动隐藏控件：

| 当前状态 | 点击画面或黑色留边的空白处 |
| --- | --- |
| 正在播放、控件隐藏 | 仅显示控件，继续播放 |
| 正在播放、控件可见 | 暂停，保持控件显示 |
| 已暂停或已播完 | 继续播放／从头重播，保持控件显示并重新计时 |
| 选集、评论或设置面板展开 | 只关闭面板，保持播放状态 |
| 距最后一次滚动不足 600ms | 忽略画面单击；按钮及空格仍直接播放／暂停 |

暂停、缓冲、加载、错误、面板打开时保持控件显示。悬停控件、拖动进度条、
键盘在控件内操作、编辑弹幕时暂停自动隐藏计时；结束这些操作后重新等待 4 秒。
鼠标在普通画面移动只延长已显示控件的时间，不唤出隐藏控件，避免移动后
点击意外暂停。隐藏时 Esc 只显示控件，再按 Esc 按既有规则退出全屏／播放。

不提供“详情”“清屏”“退出清屏”按钮。剧名使用 MyGo `Link`，点击进入当前
剧集详情。显示状态不写入偏好文件；进入新的播放会话先显示控件。弹幕继续
显示，隐藏期间不弹出弹幕互动控件。隐藏或显示不重新加载视频，暂停仍保存进度。

## 调研依据与本应用取舍

- [YouTube 播放控件说明](https://support.google.com/youtube/answer/9047376?hl=en)：
  播放期间点击显示控件，暂停时显示控件。
- [Apple TV 播放控件](https://support.apple.com/en-mt/guide/tvapp/atvb5e386e66/1.0/web/1.0)：
  控件闲置后消失，唤出控件与播放／暂停分开。
- [Netflix 键盘快捷键](https://help.netflix.com/en/node/24855)：
  空格／Enter 提供明确的播放暂停操作。

各平台和设备并不采用完全相同的点击行为。推荐流不响应画面单击暂停、
剧集页二次点击暂停、4 秒闲置和 600ms 滚动保护是本应用针对桌面触控板的选择。

## 实现与验证

MyGo v0.9.1：保留 `ButtonBase`、`SliderBase`、`Link` 原有命中和键盘语义。
使用 `ObserveInput` 监听按下及键盘；本版本观察器不派发滚动和移动事件，
因此滚动用不消费事件的 `HandleInput`，移动用 `PointerPosition`。
拖动用滑块的 `PressedButton`，不维护可能因窗口外松开而卡住的按住标记。
控件悬停／键盘焦点用 `PointerPosition`／`FocusWithin`。4 秒策略放在现有
控制器时钟中，UI 不添加计时器或动画轮询。沿用共享 140ms 淡入淡出过渡，
系统减少动态效果偏好由 MyGo 处理。

回归覆盖推荐流重复点击与滚动、剧集隐藏后唤出／暂停／继续、滚动保护窗口、
显式暂停按钮和空格、Esc、连续快速点击、面板及剧名命中、悬停与编辑弹幕、
拖出播放器后松开进度条、鼠标移动、各阻塞状态结束后的重新计时，以及保持
视频源、暂停进度和会话偏好。原生 UI 事件使用 `ui.NewTester`，时间策略使用
可控时钟，不等待真实 4 秒。
