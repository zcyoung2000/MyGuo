# 播放页点击交互

播放页移除“详情”“清屏”“退出清屏”按钮。剧名使用 MyGo 的 `Link`，
保持白色文字，悬停时显示下划线与“查看剧集详情”提示，点击进入当前剧集详情。

| 当前状态 | 点击画面或黑色留边的空白处 |
| --- | --- |
| 正在播放、控件可见 | 收起控件，继续播放 |
| 清屏播放 | 暂停并显示控件 |
| 已暂停或已播完 | 继续播放／从头重播，并收起控件 |
| 选集、评论或设置面板展开 | 只关闭面板，保持播放状态 |

空格保持直接播放/暂停；清屏时 Esc 先显示控件。清屏不写入偏好文件，
重新进入播放器时显示控件。弹幕继续显示，清屏期间不弹出弹幕互动控件。
控件显示与收起使用共享的短淡入淡出动画。

空白点击在播放控制器中按顺序处理，不依赖可能滞后的 UI 快照；
隐藏控件不重新加载视频，暂停仍保存进度。系统或键盘暂停也会显示控件。

修复了初次布局时透明弹幕层可能截获点击，以及剧名锚点可能在按下和抬起
之间移动的问题。布局容器和控件之间的透明空隙允许点击穿透，实际控件仍
独立响应。

验证覆盖原生页面点击、剧名跳转、控件及面板命中、空格、Esc、连续快速点击、
暂停进度、保持视频源与会话偏好，以及完整 Go 测试、相关包竞态检查和 macOS 打包。
