# 找剧页：官方筛选条件与页面重写

2026-11-14 直接读取官方接口：
`POST https://api5-normal-sinfonlinea.fqnovel.com/reading/distribution/category/landpage/v1/`。
面板使用 `req_type=only_panel`，结果使用 `req_type=only_content`；
真人剧的 `req_scene=default`，漫剧和 AI 剧分别使用 `comic_series`、`ai_series`。
结果请求始终同时携带 `select_items.genre`。

## 实际返回

| 分组 | 官方字段 | 真人剧 | 漫剧 | AI 剧 |
| --- | --- | --- | --- | --- |
| 主题 | category_dim_theme | 有 | 有 | 有 |
| 设定 | category_dim_role | 有 | 有 | 有 |
| 背景 | category_dim_epoch | 有 | 有 | 有 |
| 推荐排序 | sort | 最新上架、最高热度、最高收藏 | 同左 | 同左 |
| 受众 | gender | 男频、女频 | 同左 | 同左 |
| 上新时间 | online_time | 7、14、30、90 天内 | 同左 | 同左 |
| 画风 | category_dim_art_style | 无 | 部分设备返回 3D漫、2D漫、表情包 | 无 |
| 作品状态 | creation_status | 无 | 已完结、连载中 | 无 |

首次实测，真人剧的主题/设定/背景分别为 26/80/24 项，漫剧为
26/95/34 项，AI 剧为 8/8/9 项。另一次设备会话中，漫剧返回
8/8/9 项且没有画风分组。上述数量只描述观测样本，产品不按数量或名称
写死条件。页面保留服务端行顺序，按当前体裁实际返回的数据渲染。

只含公开分类名称与选项值的首次响应快照保存在
`internal/catalog/testdata/filter_panels.json`；不包含账号、设备、签名或会话数据。

## 修复与页面行为

- 找剧页布局集中到 `internal/uiapp/catalog_view.go`，请求与状态集中到
  `internal/uiapp/catalog.go`。继续复用 `surfaces.go` 的深色材质和
  `ui_motion.go` 的动效参数。
- 体裁切换放到标题行，收起筛选或滚动时仍然可用；各体裁的条件和选择
  分别保存，切回恢复。长分组按需展开，已选条件保持可见，并提供清除筛选。
- 选项使用 MyGo v0.9.0 的 `RadioBase` / `RadioGroup`，体裁使用
  `SegmentedBase`，折叠使用 `CollapsibleBase`；键盘、单选语义与焦点由原语负责。
- 筛选面板和结果使用独立的请求代次与失败状态。请求发起前在锁内捕获
  体裁与条件，旧结果不会覆盖新体裁。条件重置后禁止先行翻页，避免把新体裁
  第一页拼到旧体裁的列表后面。异步返回的索引不会用来选择另一体裁的条件。
- 点击通过原生控件构建后的回调顺序提交，网络请求仍异步执行。
- 刷新期间保留已加载的结果；筛选面板失败有独立重试，不遮住结果。
- 规范化时只添加一个“全部”，保留每组真实选项值；查询始终明确提交体裁。

当前使用的第三方 SDK 能解析画风，却在查询前用固定字段列表拒绝它。
`internal/filterapi` 提供小范围兼容：普通请求仍完整走 SDK，只有画风查询
才补入该官方字段，按最终请求体重新签名。设备注册、响应解析、重试及游标
仍由 SDK 负责；外层游标额外绑定画风，切换画风后不能误用旧游标。
账号传输层在发出请求前调用兼容处理，其他接口的请求不变。

## 验证

- 三种体裁的真实默认查询、主题查询和第二页读取通过；漫剧画风查询及第二页
  也返回结果。`go run ./cmd/catalog-diagnose -verify-content` 可在内存匿名会话
  中复查，不读写用户账号数据库。
- 完整 SDK → 画风兼容 → 账号传输 → HTTP 测试验证最终请求体签名、账号头、
  分页和跨画风游标拒绝。
- 回归覆盖官方快照差异、体裁隔离与恢复、过期面板返回、独立重试、重置后
  禁止错误翻页、真实原生点击和选中标签文字层级。
- 三种体裁在 760、1000、1280 宽度下验证布局。可设置
  `MYGUO_CATALOG_SHOTS` 导出实际页面渲染器的预览，封面是本地验收素材，
  不代表用户实际片单。
